RAG Simulator

Interactive Retrieval-Augmented Generation simulator to help understand: document ingestion, chunking, embeddings, vector databases, retrieval, and LLM response generation.

STEP 1

Knowledge Base Input

Add PDFs, documents, or website text into the knowledge base.

STEP 2

Chunking

Large documents are broken into smaller chunks so retrieval becomes efficient.

STEP 3

Embeddings + Vector DB

Each chunk gets converted into embeddings (numerical vectors) and stored inside a vector database.

STEP 4

User Query

User query is also converted into embeddings. Similar chunks are retrieved using semantic similarity.

STEP 5

LLM Generation

Retrieved chunks + user query are passed to the LLM to generate the final grounded answer.
